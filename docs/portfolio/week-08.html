CatatanPaket aktif menjadi acuan

Urutan sesi adalah 1, 2a, 2b, 3a, 3b. Ikuti penugasan target dan versi di ZIP sendiri, bukan target contoh. Prioritas konfigurasi mengikuti PENUGASAN, prompt umum, profil, dan template. Periksa kebutuhan password pada paket aktif; bila tidak terbaca, ekstrak ke folder terpisah agar berkas antarsesi tidak tertimpa. Sesi 2b dan 3b dimulai baru dengan target berbeda, tanpa mewarisi kepercayaan tokoh sebelumnya.
